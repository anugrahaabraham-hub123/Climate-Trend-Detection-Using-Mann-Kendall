# Figures

This directory contains visualization generated from the seasonal Mann–Kendall trend analysis.

## Included Figure

**Seasonal_Kendall_Tau_Combined.png**

This combined figure presents the spatial distribution of Kendall's Tau values for aerosol radiative forcing across the Indian subcontinent from **1980–2024**.

Kendall's Tau (τ) is a rank-based correlation coefficient that measures the strength and direction of a relationship between two variables, like time and data values. It ranges from -1 (strong decreasing trend) to +1 (strong increasing trend), with values near 0 indicating no significant trend.

The figure contains four panels corresponding to:

- Winter (DJF)
- Pre-Monsoon (MAM)
- Monsoon (JJAS)
- Post-Monsoon (ON)

Each panel highlights the seasonal trend strength.
